# Herdr custom mod

This folder owns non-sidebar additions. Sidebar behavior and state live in
`/mnt/PROJECTS/herdr-app-mods/over9k-sidebar/over9k/mods`, symlinked into Herdr.

- `main.js` owns the custom tab actions and the native blocked-agent toast.
- `herdr-permission-blocked.ts` is the OMP permission bridge implementation.
  `~/.omp/agent/extensions/herdr-permission-blocked.ts` only re-exports it;
  edit the implementation here, then restart OMP to load extension changes.
  The bridge sets Herdr's blocked status; `main.js` draws the native toast.
- `mods/auto-tabs` is upstream and must stay untouched.
- The sidebar source of truth is the user's `JasonLandbridge/herdr-over9k`
  checkout, not installed copies or generated `over9k-sidebar/mods` bundles.
  Edit sidebar UI, visibility/status reducers, context menus and worktree
  ordering in `over9k/mods` there. Cross-mod runtime imports are unsupported.
- Visibility and status presentation must preserve raw agent statuses,
  running terminals, workspace structure, notifications and native navigation.
- Activity tracking is observer-session based: reset on sidebar startup,
  including reload/layout recreation. Do not infer work from focus, titles or
  status sequence numbers.
- Preserve local visibility/status behavior, worktree block sorting and existing
  UI changes. Keep installed sidebar-suite paths as symlinks to this checkout.
- Worktree creation hooks belong in the fork's `over9k-worktree` mod; leave
  shipped `mods/worktree` unchanged. Personal rules live in
  `~/.config/herdr-app/worktree-hooks.json`, matched by machine and main checkout.
  Run creation hooks in the new checkout; opening/removing must not run them.
- `mods/tabs` and other upstream mods remain unmodified.
- `keys.json` and `layouts/main-custom.json` remain user configuration, not
  generated by this mod.
- Add non-sidebar customizations here. Other upstream-internal changes require
  approval; the user-owned sidebar repository is the approved exception.
- After editing: `herdr-app check ~/.config/herdr-app/mods/herdr-custom`, then
  `herdr-app status` and confirm `errors` is empty.
- The app's `~/.config/herdr-app/AGENTS.md` is rewritten on every start;
  this file is the persistent rule for this custom mod.
